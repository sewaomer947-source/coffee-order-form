# Coffee Order Form Web Application

A responsive frontend web application featuring an interactive coffee ordering interface built with Bootstrap 5 and client-side form logic.

## 💻 Project Overview
This project provides a clean, user-friendly interface for customizing and submitting beverage orders. It leverages HTML5 input validation and Bootstrap 5 UI components for a smooth user experience across devices.

## 🛠️ My Specific Contributions (Sewa Omer)
* **Architecture & Layout:** Designed and structured the HTML5 form hierarchy, selecting Bootstrap 5 grid utilities and custom color palettes to ensure high readability.
* **Form Logic & Validation:** Implemented native HTML5 input constraints (`required` fields, numeric ranges, and field types) to validate user input before submission.
* **AI-Augmented Workflow:** Used AI tools to draft initial Bootstrap boilerplate components, which I then manually refined, re-styled with custom CSS, and structured for optimal usability.
