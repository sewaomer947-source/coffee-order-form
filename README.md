# Coffee Order Form Web Application

A responsive frontend web application featuring a coffee ordering interface built with Bootstrap 5 and interactive form logic.

## 💻 Project Overview
This project provides a clean, user-friendly interface for ordering coffee beverages, featuring custom styles, layout structure, and responsive design elements.

## 🛠️ My Specific Contributions (Sewa Omer)
* Designed and structured the core HTML layout and Bootstrap 5 UI elements for the coffee order form.
* Implemented client-side form controls and responsive styling to ensure seamless usability across devices.
* Utilized AI tools to assist in writing, structuring, and debugging frontend code efficiently.
